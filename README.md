# LumiScreenReader

**화면에 있는 글을 소리로 읽어 주는 프로그램입니다.**
문서·웹 페이지·메일 등 어느 프로그램의 글이든, 키 하나로 부르면 읽어 줍니다.

## 무엇에 쓰나

- 눈이 피로할 때, 긴 문서를 **끝까지 훑어야** 할 때
- 내가 쓴 글을 **소리로 들으며 교정**할 때 — 눈으로는 지나치는 오타가 귀에는 걸립니다
- 화면을 오래 보기 어려운 분이 **다른 일을 하면서** 읽을 때

## 어떻게 읽히나

두 가지 방법이 있고, 무엇을 읽을지는 **줄마다 따로** 정합니다.

| | 하는 법 |
|---|---|
| **두 번 톡톡** | <kbd>Shift</kbd>·<kbd>Ctrl</kbd>·<kbd>Alt</kbd> 중 하나를 **연달아 두 번** 가볍게 누릅니다 |
| **핫키** | 지정한 키 하나. 기본값은 <kbd>Pause</kbd>·<kbd>ScrollLock</kbd> — 아무 프로그램도 쓰지 않는 키라 **한 손으로** 누릅니다 |

읽는 것은 **선택한 글** 또는 **마우스 아래 문단**입니다.
읽는 중에 같은 방아쇠를 다시 당기면 멈춥니다.

## 목소리 두 가지

| | 경량 | 고음질 |
|---|---|---|
| 비용 | **무료** | [LumiVoice](https://github.com/civilian7/LumiVoice) 필요 |
| 읽는 곳 | 이 컴퓨터의 Windows 음성 | LumiVoice |
| 다른 프로그램 | 필요 없음 | LumiVoice 가 떠 있어야 함 |
| 반응 | 즉시 | 첫 문장에 준비 시간 |

**이 프로그램만으로도 무료로 다 쓸 수 있습니다.** 고음질은 더 자연스러운 목소리를
원할 때의 선택입니다 — 어떤 소리인지는 프로그램 안의 **도움말 → 고음질 미리 듣기**에서
설치 없이 들어 보실 수 있습니다.

## 밖으로 나가지 않습니다

- 읽는 글이 **인터넷으로 나가지 않습니다.** 화면 낭독은 문서·메일처럼 남에게 보일 수
  없는 내용을 읽는 일이라, 이것이 이 제품의 전제입니다.
- **사용 기록을 수집하지 않습니다.** 기록은 이 컴퓨터에만 남고, **읽은 글도 창 제목도**
  남기지 않습니다 — 창 제목에는 문서명·환자명·메일 제목이 옵니다.
- 고음질도 마찬가지입니다. LumiVoice 는 **같은 컴퓨터 안에서** 음성을 만듭니다 —
  **API 요금이 없고**, 그래픽 카드(GPU)도 필요 없습니다.

## 필요한 것

| | |
|---|---|
| 운영체제 | **Windows 10 (64비트) 이상** — 32비트에서는 동작하지 않습니다 |
| 음성 | Windows 에 설치된 **한국어 음성** 하나. 없으면 프로그램이 뜨지 않고 설치하는 곳을 안내합니다 |
| 설치 | **압축을 풀고 실행하면 됩니다.** 관리자 권한이 필요 없습니다 |

설정·기록은 프로그램 폴더 아래 `userdata` 에 쌓입니다(무설치판). 폴더째 옮기거나
USB 에 담아도 그대로 따라갑니다.
